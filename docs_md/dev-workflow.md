# Dev workflow

## Ground rules for agents working with this user

- The user is **non-technical**. Run everything yourself — builds, installs,
  DB inspection, log reading. Never hand them commands to run. Report
  results in plain language; keep technical detail out of chat unless asked.
- Ship in small, verified steps. After any change: verify → build → install →
  tell them what to test. Commit and push (their own fork) without asking.
- Diagnose from evidence, not guesses: `~/.local/share/com.pais.handy/logs/handy.log`
  first, then the DB, then code.

## Verify loop (run before every commit)

Backend (from `src-tauri/`):

```bash
source ~/.cargo/env && cargo fmt && cargo check && cargo test --lib
```

All tests must pass (260+ and growing). New logic gets tests — the pure
helpers (voice command parsing, speaker attribution, keyword extraction) are
all unit-tested; follow suit.

Frontend (from repo root):

```bash
npx tsc --noEmit
npx eslint <changed files>       # i18n rule: no hardcoded JSX strings
npx prettier --write <changed files>
node --experimental-strip-types scripts/check-translations.ts   # all 24 locales complete
```

Known pre-existing debt (do not "fix" in passing): 2 i18n lint errors in
`ProgressBar.tsx` (upstream), unused `Emitter` import warning in
`secure_input.rs`, an unused-assignment warning in `transcription.rs`.

## Release build & install

```bash
export PATH="$HOME/.bun/bin:$PATH" && source ~/.cargo/env && bun run tauri build
```

- Run it in the background; a full rebuild is ~15–30 min (frontend-only
  changes still trigger a large Rust relink; touching `transcription.rs`
  rebuilds a lot).
- Artifacts land in `src-tauri/target/release/bundle/`:
  `deb/Noted_0.9.6_amd64.deb` (the one we install), plus `.rpm` and
  `.AppImage`.

Install (passwordless sudo is NOT available; `pkexec` opens a GUI password
dialog on the user's screen — tell them it's coming):

```bash
DISPLAY=:0 pkexec apt-get install --reinstall -y /home/zawuoff/work/noted/Handy/src-tauri/target/release/bundle/deb/Noted_0.9.6_amd64.deb
```

Then the user must quit the running app from the tray and relaunch.

Dev mode instead: `bun run tauri dev` (kill stale ones first:
`fuser -k 1420/tcp; pkill -f "target/debug/handy"`).

## <a name="bindings"></a>bindings.ts sync (important)

`src/bindings.ts` is generated by tauri-specta **only when the app runs**.
Since agents usually don't run the dev app, the convention is to hand-edit
`bindings.ts` in the exact generated style (same `TAURI_INVOKE` wrapper,
same Result shape, doc comments mirrored from the Rust `///`). Checklist for
a new command:

1. Rust: `#[tauri::command] #[specta::specta]` fn
2. Register in `lib.rs` `collect_commands![…]`
3. Hand-add to `bindings.ts` `commands` object (+ any new types)
4. If it's an event: define with `tauri_specta::Event` derive and mirror the
   type + `events` entry in `bindings.ts`

If a later dev run regenerates the file, dedupe keeping the generated copies
(this happened once).

## i18n

Every user-visible string: add the key to
`src/i18n/locales/en/translation.json` **and all 23 other locales** (write a
small python script over `src/i18n/locales/*/translation.json`, as done
throughout this project's history). `check-translations.ts` fails the build
otherwise. Tray strings live separately in the Rust-side `tray_i18n`
translations.

## Git

- Conventional commits (`feat:`, `fix:`, `docs:`…), message body explains
  _why_. End with the Co-Authored-By trailer for the agent.
- Push to `origin main` (`github.com/zawuoff/Handy`). No upstream PRs —
  upstream declined meeting features (feature freeze).
- If you ever do interact with upstream, `.github/` templates are mandatory
  (see `AGENTS.md`).

## Debugging quick reference

- Logs: `~/.local/share/com.pais.handy/logs/handy.log` (Debug level is on).
  Grep for `diariz`, `Voice command`, `Stream pause reset`,
  `Live preview: model`, `notes` as entry points.
- DB: no `sqlite3` CLI on the machine — use python's `sqlite3` module.
- Test a model against a WAV offline: `handy --transcribe-file <path>`.
- Debug UI: `Ctrl+Shift+D` in the app.
- The tray icon state PNGs are `src-tauri/resources/{handy,recording,transcribing}.png`
  (currently all the Noted logo, 64×64 — dedicated state art is a TODO).
